# CodeFoundry — Flagship Coding Academy Website

A static multi-page HTML/CSS/JS concept with a dark developer-product identity and four independent portfolio identities.

## Pages
- index.html — high-impact landing page
- courses.html — learning tracks
- challenges.html — interactive coding challenge
- projects.html — project marketplace
- dashboard.html — developer dashboard
- portfolio.html — showcase hub

## Independent portfolios
- portfolios/alex.html — editorial / minimal
- portfolios/maya.html — experimental / creative
- portfolios/arjun.html — luxury technology
- portfolios/sofia.html — AI research / computational

## Assets
The visual system is intentionally CSS-driven so the site works immediately without image files. Replace the generated CSS artwork blocks with your preferred production photography/3D renders in `assets/images/`.

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.
